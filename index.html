01 / The problem

A map can be correct
and still be wrong.

Most embodied navigation systems treat memory as a snapshot of the world. Long-lived agents cannot. Homes, offices, and campuses evolve while unobserved: objects move, rooms are rearranged, and accessibility changes.

EvolvingWorldNav asks a more realistic question: what task-relevant state is most likely true now? The agent turns timestamped history into a calibrated belief, acts to test that belief, and writes new evidence back into memory.

“

Our work shifts embodied navigation from acting on remembered past observations toward maintaining, testing, and acting on beliefs about the world as it is now.

02 / The method

From causal history
to current-state belief.

A compact action-facing interface for long-term embodied agents.

ASYSTEM OVERVIEW

Predict, act, observe,
update.

Timestamped RGB-D experience is consolidated into persistent entity histories, transformed into a task-conditioned belief, and exposed to an embodied agent through typed memory and action skills.

BSTRUCTURED BELIEF
belief=persistence+relocation

The model separates whether the last state persists from where an object may relocate, matching the physical alternatives available to the navigator.

CEVIDENCE LOOP
belief→inspect→observe→replan

Visibility-aware Bayesian updates suppress a hypothesis only when the target should have been observable there.
