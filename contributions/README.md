# Independent contributor workspaces

This directory keeps the three contributors' uploads isolated so that data and
documentation can be revised without overwriting another contributor's files.

Each contributor should use one stable directory:

```text
contributions/
  <contributor-name>/
    README.md
    datasets/
    figures/
    notes/
```

Only create the subdirectories that are needed. Changes to another contributor's
directory should be made through review rather than direct replacement.
