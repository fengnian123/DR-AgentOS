\subsection{Construction and Audit Details}
\label{app:benchmark-construction}

\paragraph{Source alignment and provenance.}
The generator combines longitudinal smart-home records from CASAS
\citep{cook2013casas} and ARAS with multi-week activity and object-location
sequences from HOMER+ \citep{patel2023routine}. HD-EPIC provides fine-grained
egocentric action traces, and ParaHome provides reconstructed human--object
interactions \citep{perrett2025hdepic,kim2025parahome}; OPPORTUNITY supplies
complementary evidence. A common event schema records time, activity, actor
context, object category, source state, destination state, and evidence
provenance. Source statistics constrain schedules, activity--object
associations, transition timing, and placement tendencies. No source trajectory
is copied verbatim into simulation, and unsupported quantities are labeled
benchmark-authored rather than measured human behavior.

\paragraph{Household generation and behavioral checks.}
For each HSSD scene \citep{khanna2024hssd}, resident schedules, room preferences,
orderliness, object ownership, and placement habits are fixed at the household
level. Activities, resident region trajectories, and object transitions are
generated jointly in chronological order; stochastic events, delayed returns,
and exceptions prevent deterministic histories. Every relocation is attributed
to an activity, resident transition, object lifecycle event, or tidying event.
Audits check that personal objects do not simply track their owners and that
actor or activity identity does not predict irregular destinations beyond
affordance. The audited configuration yields 42.6 region transitions per
resident-day, 6.56 relocations per personal object-day, 52.6\% within-region
relocations, and zero terminal collisions.

\paragraph{Candidate metadata and query sampling.}
Chronological replay records navigability, geodesic cost, camera frustum
coverage, unoccluded target fraction, and success viewpoints for each candidate.
These fields support the physical validity and visibility checks described in
\cref{app:audit}. Query times sample both the natural temporal distribution and
mechanism-relevant windows, including routine stages and intervals after a
personal object is dropped. Each navigation query is augmented with a start
pose, candidate inspection viewpoints, a path budget, and fixed success
conditions.

\paragraph{Language tasks and release documentation.}
EQA questions cover existence, location, temporal order, activity association,
count, comparison, and compositional relations over the same causal memories.
Answers are evaluated against a normalized ontology, and questions requiring
future evidence are excluded. VLN replaces the object label with a language
goal whose referents and constraints are grounded in the same versioned scene
history. The broader task annotations are included for studies beyond the
prediction and navigation experiments emphasized in this paper. Dataset cards
and audit summaries document source mappings, authored assumptions, physical
validity, candidate coverage, and leakage tests; episode-level leakage checks
and mobility assignment are described in \cref{app:audit,app:mobility}.
