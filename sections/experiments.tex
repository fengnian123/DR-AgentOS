\section{Experimental Setup}
\label{sec:experiments}

\paragraph{Benchmarks.}
We evaluate memory-facing behavior on \textbf{LMEE-Bench} \citep{wang2026explore}, which tests long-term memory over exploration histories, and \textbf{OpenEQA} \citep{majumdar2024openeqa}, which tests embodied question answering over ScanNet and HM3D environments. For OpenEQA we use episodic-memory EQA: the agent answers from a fixed, fully observed episode rather than actively exploring.

\paragraph{Metrics and protocol.}
For LMEE-Bench we follow the official multiple-choice and open-answer protocols, reporting choice accuracy and normalized open-answer score on Easy, Medium, Hard, and overall splits. The categories cover attributes, state, location, relations, and counting. For OpenEQA we follow environment-based reporting and use LLM-Match on ScanNet, HM3D, and their combined question set. Ground-truth answers are withheld from the agent and used only for scoring. Frame budgets are reported separately because the benchmarks sample episode history differently.

\paragraph{Comparisons.}
We distinguish direct multi-frame VQA systems, which answer from sampled frames without persistent scene state, from memory-based systems using captions, scene graphs, snapshots, or learned long-term memory. \dragentos{} uses the same persistent 4D memory and task-conditioned retrieval interface in both evaluations. Exact model versions, prompts, inference settings, hardware, and run-level aggregation must be recorded with the final benchmark results; the required reporting checklist appears in \cref{app:protocol}.
