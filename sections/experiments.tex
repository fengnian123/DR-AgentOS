\section{Experimental Setup}
\label{sec:experiments}

\noindent\textbf{Benchmarks.}
We evaluate \dragentos{} on two embodied memory and question-answering benchmarks. \textbf{LMEE-Bench} \citep{wang2026explore} evaluates long-term memory over exploration histories using both multiple-choice and open-ended questions. \textbf{OpenEQA} \citep{majumdar2024openeqa} evaluates embodied question answering over ScanNet and HM3D environments. We use its episodic-memory setting (EM-EQA), in which the agent answers questions from a fixed, fully observed episode history without active exploration.

\noindent\textbf{Evaluation Protocol.}
For LMEE-Bench, we follow the official choice and open-answer protocols. We report choice accuracy and normalized open-answer score for the Easy, Medium, and Hard task splits, together with the overall result. These difficulty-stratified metrics capture the increasing number of visited targets and the longer memory horizon of more complex exploration instructions. The benchmark questions span attribute, state, location, relationship, and counting categories. For OpenEQA EM-EQA, we follow its environment-based reporting convention and report LLM-Match separately on ScanNet and HM3D episodes and over the combined set. Ground-truth answers are withheld from the agent and used only for post-hoc scoring. The number of input frames is reported independently for each benchmark because the two evaluation pipelines use different episode sampling budgets.

\noindent\textbf{Compared Methods.}
Following the organization of prior embodied EQA comparisons, we group baselines into direct multi-frame VQA references and memory-based embodied methods. Direct VQA systems answer from sampled episode frames without an explicit persistent scene representation. The LMEE-Bench comparison includes MemoryExplorer, the benchmark's long-term-memory reference method, while the OpenEQA comparison follows the caption-, graph-, snapshot-, and 3DGS-memory families used for EM-EQA. \dragentos{} uses its persistent 4D world memory and task-conditioned evidence retrieval in both settings.
