\section{Conclusion}

We introduced persistent dynamic object navigation, a setting in which an embodied agent must act on a long-term but potentially stale history of a changing environment. \pfdnav{} treats 4D memory as a predictive belief rather than a last-seen database: it separates persistence from relocation, represents variable scene-specific candidates, converts visibility-qualified observations into posterior evidence, and uses the evolving distribution to navigate, search, and replan. \pfdbench{} grounds this question in human-trace-driven HSSD episodes and paired static, routine, and random worlds. The resulting formulation evaluates a simple but consequential capability for long-lived agents: navigating not merely to where an object was observed, but to where the accumulated evidence indicates it is now. Quantitative conclusions will be added only after the multi-scene navigation evaluation is complete.
