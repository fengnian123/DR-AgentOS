\section{Conclusion}

\evolvingworldnav{} turns irregular object histories into a persistence--relocation
belief and revises navigation using visibility-qualified evidence.
\pfdbench{} evaluates this loop under hidden world evolution, with paired
controls showing that predictive gains depend on learnable temporal structure.
Cross-benchmark and physical results support the value of combining prediction
with evidence gathering: persistent navigation requires maintaining alternative
locations and revising them when observations contradict memory.
