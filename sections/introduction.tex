\section{Introduction}
\label{sec:introduction}

Object navigation asks an embodied agent to find a requested object from egocentric observations. Semantic mapping and foundation-model reasoning have made this problem increasingly tractable in static environments \citep{chaplot2020objectnav,huang2023vlmaps,gu2024conceptgraphs}. Long-lived agents, however, may operate for months in relatively stable homes, offices, and campuses whose contents evolve while unobserved. A mug last seen beside the sink may now be on a desk; keys may alternate between a shelf and a bag. The agent retains a valid historical observation but faces an uncertain current navigation goal.

Long-term deployment creates a dual tension. A persistent agent is not a persistent observer: as its \emph{4D history} grows, individual records become stale, yet their repetition reveals object dynamics, household routines, and personal habits. More history therefore does not automatically mean better knowledge of the present. Meanwhile, history grows without bound, whereas decision-time context and computation must remain controlled. Most embodied memories are retrospective, organizing or retrieving what was observed \citep{liu2024dynamem,kurenkov2023dynamic}; a predictive memory should instead answer \emph{where is the object likely to be now, how uncertain is that belief, and where should the agent search next?} We seek a decision-preserving interface in which the episodic store retains grounded facts while the action policy consumes a compact, task-conditioned belief that preserves prediction and search utility.

Recent work models temporal persistence, future relations, household routines, and targets that move during navigation \citep{saavedraruiz2026predictivegraphs,patel2023homer,argenziano2026flowmaps,dorbala2026portable}. These approaches establish that dynamics matter, but a complementary gap remains: memory must reason through periods without observation, not only update after changes are seen. How should an agent transform its own growing, partial history into a predictive belief that directly drives physical search and is corrected by evidence collected along the route?

We formulate this setting as \textbf{persistent dynamic object navigation}. Before a query, the agent has repeatedly visited the same household and accumulated timestamped observations. The target may undergo hidden transitions after its last positive observation, but the agent receives neither its current state nor the activity that caused the change. It must find the object under a navigation budget using only causal memory, candidate receptacles and viewpoints, and online RGB-D observations. Our main protocol freezes the target after the query to isolate prediction from stale history; an extension allows another hidden transition during navigation.

We introduce \pfdnav{}, a long-term agent centered on \textbf{4D Predictive Memory}. Its 4D store maintains persistent identities, time-valid states, and observation provenance in a common frame. A causal retriever selects target-relevant history, and a lightweight continuous-time Transformer represents irregular gaps and calendar periodicity. A structured head factorizes the current belief into the probability that the last-seen state persists and a pointer distribution over relocation candidates. This matches the navigator's physical alternatives, supports variable candidate sets, and exposes the belief---rather than the event sequence---as the memory interface to the action policy.

Prediction is embedded in a closed decision loop. Concentrated beliefs support a direct attempt; diffuse beliefs induce a probability--cost search order. Navigation returns new RGB-D evidence, and a visibility-aware Bayesian update suppresses an inspected hypothesis only when the target should have been observable there. The agent then replans from the posterior. The same controller handles rare, routine, personal, and irregular targets without an oracle mobility label, connecting history $\rightarrow$ belief $\rightarrow$ search $\rightarrow$ evidence $\rightarrow$ belief update.

We evaluate this capability with \pfdbench{}, a benchmark for predictive memory and dynamic target search in HSSD households. Its episodes combine longitudinal activity records, real human--object interaction traces, and household object-state scripts. Evaluation measures belief quality, navigation efficiency and recovery, and whether smaller decision contexts preserve performance relative to fuller histories. Paired static, routine, and random worlds share the scene, target, last observation, query time, candidates, start, and budget while differing only in the hidden transition process. This design tests whether gains come from learnable temporal structure rather than object--location frequency or route geometry.

\paragraph{Contributions.}
Our contributions are threefold:
\begin{itemize}[leftmargin=5mm,itemsep=0.6mm,topsep=1mm]
    \item We formulate \textbf{persistent dynamic object navigation}, exposing long-term history as both stale state evidence and a source of temporal regularities under controlled decision context.
    \item We introduce \pfdnav{} and \textbf{4D Predictive Memory}, which turn causal history into an action-facing persistence--relocation belief and close the loop through physical evidence and replanning.
    \item We introduce \pfdbench{}, a human-trace-grounded HSSD benchmark that jointly evaluates prediction, context efficiency, and embodied search with paired static/routine/random controls.
\end{itemize}
