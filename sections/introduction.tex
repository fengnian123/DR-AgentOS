\section{Introduction}
\label{sec:introduction}

Embodied agents increasingly translate open-ended instructions into actions grounded in perception. Foundation models broaden the goals robots can interpret, while open-vocabulary maps and scene representations provide semantic grounding beyond fixed object classes \citep{ahn2022saycan,driess2023palm,huang2023vlmaps,gu2024conceptgraphs}. Real deployments, however, are not isolated episodes in static scenes. A robot may revisit a building over days or months, receive tasks that depend on earlier observations, and encounter changed objects, access conditions, or routes. It must therefore preserve and revise a grounded account of the world, not merely recognize the current view or predict a plausible next action.

Existing work addresses complementary pieces of this problem. Semantic maps and hierarchical scene graphs organize spatial entities and relations \citep{huang2023vlmaps,gu2024conceptgraphs,werby2024hovsg}; dynamic and lifelong mapping models changes in geometry or object state \citep{bescos2018dynaslam,narayana2020lifelong,liu2024dynamem}; and embodied-agent frameworks connect foundation-model reasoning to callable skills and multimodal memory \citep{zhou2026holoagent,tian2026abot,wang2026thea,li2026agenticnav}. Yet task context, spatial memory, tool execution, and state update are often maintained by separate components without a shared contract for identity, temporal validity, provenance, and execution authority.

That missing contract creates a practical failure mode: a fluent controller can convert uncertain observations or successful software calls into unsupported facts. Object coordinates must originate from mapping, robot poses from the execution backend, and task completion from observed outcomes rather than a planner's return value. Likewise, disagreement with memory may indicate a persistent change, but it may also arise from occlusion, association error, or a transient condition. Long-term operation thus needs both an evolving world model and an explicit policy governing which evidence may change it.

We present \dragentos{}, a persistent embodied agent operating system built around a typed Agent Controller and a 4D World Memory. The memory represents 3D semantic structure and temporal evolution under persistent identities. Observations are projected into a common frame and organized as a \textbf{Timeline--Floor--Room--Object} hierarchy; mutable attributes occupy time-valid versions, and every assertion remains linked to observations, poses, timestamps, and confidence. Here, ``4D'' denotes an executable, reconstructable world model rather than a sequence of timestamped frames.

Access to this memory is task conditioned. A structured query selects a causal memory view, after which multimodal retrieval combines descriptions, object crops, scene context, and relations. A constrained vision-language model (VLM) may select only from retrieved entities or abstain; it cannot invent an identity or edit a coordinate. The same source-grounded discipline governs execution: typed tool calls pass through validation, returned evidence is checked before task progress is committed, conflicts trigger active verification, and only corroborated changes become new persistent versions.

We evaluate memory-facing capabilities on LMEE-Bench \citep{wang2026explore} and OpenEQA \citep{majumdar2024openeqa}. These benchmarks test long-term exploration memory and episodic embodied question answering across different environments and question types.

\paragraph{Contributions.}
Our contributions are:
\begin{itemize}[leftmargin=5mm,itemsep=0.5mm,topsep=1mm]
    \item an embodied AgentOS that separates high-level reasoning from authoritative tool execution, outcome verification, and state commit;
    \item an evidence-grounded 4D World Memory unifying 3D semantics, spatial hierarchy, persistent identity, temporal versions, and observation provenance; and
    \item task-conditioned retrieval with multimodal rank fusion, relation-aware queries, constrained candidate resolution, and evidence-gated state evolution.
\end{itemize}
