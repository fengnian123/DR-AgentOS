\section{Introduction}
\label{sec:introduction}

Embodied navigation requires an agent to ground a goal, maintain a world model, and select actions from egocentric observations. Most formulations nevertheless adopt a snapshot abstraction: the map or memory is assumed to describe the same world state in which navigation is executed \citep{chaplot2020objectnav,huang2023vlmaps,gu2024conceptgraphs}. Long-lived agents violate this assumption. Homes, offices, and campuses evolve while unobserved as objects are relocated, spaces are rearranged, and accessibility changes. The agent may therefore retain evidence that is historically correct yet decisionally stale, pointing to an obsolete goal or an inefficient route.

Long-term deployment creates a dual tension. A persistent agent is not a persistent observer: as its \emph{4D history} grows, individual records become stale, yet repeated experience reveals environmental dynamics, routines, and personal habits. More history therefore does not automatically mean better knowledge of the present. Meanwhile, history grows without bound, whereas decision-time context and computation must remain controlled. Most embodied memories are retrospective, organizing or retrieving what was observed \citep{liu2024dynamem,kurenkov2023dynamic}; a predictive memory should instead infer \emph{what task-relevant state is most likely true now, how uncertain that belief is, and how navigation should adapt}. We seek a decision-preserving interface in which the episodic store retains grounded facts while the action policy consumes a compact, task-conditioned belief that preserves prediction and search utility.

Recent work models temporal persistence, future relations, household routines, and targets that move during navigation \citep{saavedraruiz2026predictivegraphs,patel2023homer,argenziano2026flowmaps,dorbala2026portable}. These approaches establish that dynamics matter, but a complementary gap remains: navigation must reason through periods in which world-state changes are not observed, rather than merely update a map after they become visible. How should an agent transform its own growing, partial history into a predictive belief that directly controls action and is corrected by evidence collected along the route?

As illustrated in \cref{fig:dr_agentos_overview}, \dragentos{} places this predictive loop in a unified embodied system. It constructs memory from conventional simulation (HM3D and MP3D), high-fidelity simulation (Habitat-GS and Interior-GS), dynamic HSSD scenes, and indoor or outdoor real-world observations. When the world evolves out of view, the agent transforms observed history into a belief over the current state, uses that belief to plan and act rather than blindly following a stale-memory route, and writes newly collected evidence back to memory. The same interface supports embodied question answering, active exploration, predictive navigation, and real-world interaction. \pfdbench{} provides the controlled simulated evaluation, while the real-world panel illustrates the deployment interface rather than a benchmark result.

We formulate the broader setting as \textbf{persistent navigation in evolving worlds}: before a query, an agent has accumulated timestamped observations through intermittent visits, while the task-relevant world state may have changed during the resulting observation gaps. We operationalize its central uncertainty through \textbf{persistent dynamic object navigation}, where a portable target may undergo hidden transitions after its last positive observation. The agent receives neither the current target state nor the activity that caused the change and must navigate under a fixed budget using only causal memory, candidate receptacles and viewpoints, and online RGB-D observations. Our main protocol freezes the target after the query to isolate reasoning over stale history; an extension allows another hidden transition during navigation.

We introduce \dragentos{}, a long-term embodied agent centered on \textbf{4D Predictive Memory}, and instantiate its predictive-navigation core as \pfdnav{}. Its 4D store maintains persistent identities, time-valid states, and observation provenance in a common frame. A causal retriever selects target-relevant history, and a lightweight continuous-time Transformer represents irregular gaps and calendar periodicity. A structured head factorizes the current belief into the probability that the last-seen state persists and a pointer distribution over relocation candidates. This matches the navigator's physical alternatives, supports variable candidate sets, and exposes the belief---rather than the event sequence---as the memory interface to the action policy.

Prediction is embedded in a closed decision loop. Concentrated beliefs support a direct attempt; diffuse beliefs induce probability--cost-aware exploration. Navigation returns new RGB-D evidence, and a visibility-aware Bayesian update suppresses an inspected hypothesis only when the target should have been observable there. The agent then replans from the posterior. The same controller handles rare, routine, personal, and irregular changes without an oracle dynamics label, connecting history $\rightarrow$ current-state belief $\rightarrow$ plan/action $\rightarrow$ evidence $\rightarrow$ memory update.

We evaluate this capability with \pfdbench{}, a 54-scene benchmark containing 90 scene-days, 239.19k dynamic state changes, and 803.68k task instances across state prediction, object navigation, vision-and-language navigation, and embodied question answering. Its evolving HSSD histories combine longitudinal activity records, real human--object interaction traces, and household state-transition programs. Our controlled analysis measures belief quality, navigation efficiency, evidence-aware recovery, and generalization. Paired static, routine, and random worlds share the observed setup while differing only in the hidden transition process, testing whether gains arise from learnable temporal structure rather than scene frequency or route geometry.

\paragraph{Contributions.}
Our contributions are threefold:
\begin{itemize}[leftmargin=5mm,itemsep=0.6mm,topsep=1mm]
    \item We formulate \textbf{persistent navigation in evolving worlds}, exposing long-term history as both stale evidence about prior states and a source of regularities for inferring the present; persistent dynamic object navigation provides a controlled operationalization.
    \item We introduce \dragentos{} and its \pfdnav{} core with \textbf{4D Predictive Memory}, which transform causal history into an action-facing persistence--relocation belief and close the loop through physical evidence, memory update, and replanning.
    \item We introduce \pfdbench{}, a human-trace-grounded, 54-scene benchmark spanning state prediction, ObjectNav, VLN, and EQA with paired static/routine/random controls.
\end{itemize}
