\section{Introduction}
\label{sec:introduction}

Long-lived robots must distinguish what they remember from what is still true,
even as the world keeps changing while they move. A bowl observed in a cabinet
yesterday may be beside the sink when a task starts, and a person may move it
again while the robot is en route; both changes can occur outside the camera
view. Accurately retrieving the earlier observation can therefore send the
robot to the wrong destination, while an initially correct prediction can
become stale before arrival. Repeatedly searching from scratch wastes
accumulated experience, whereas treating the last observation as current wastes
travel and inspection effort. Long-term navigation thus requires both retaining
evidence about the past and reasoning about its relevance to the present.

Persistent memories and open-vocabulary maps provide a foundation for this
capability by grounding objects and language in spatial experience
\citep{huang2023vlmaps,gu2024conceptgraphs,liu2024dynamem}. Predictive scene
representations and routine models go further, learning temporal regularities
in object states and placements
\citep{patel2023routine,kurenkov2023dynamic,
saavedraruiz2026predictivegraphs,argenziano2026flowmaps}. These advances
establish that history can support prediction as well as retrieval. The
question we address is how to turn that prediction into a sequence of physical
decisions while the world continues to evolve under partial observability.
Retrieving a past location does not establish that it remains valid; committing
to one predicted destination discards alternatives needed for recovery; and
failing to detect a target does not establish its absence when the view is
occluded. These failure modes motivate a belief that connects temporal
inference, inspection cost, and the reliability of new evidence.

We study \emph{persistent navigation in evolving worlds}, where an agent
answers a query using observations accumulated through intermittent visits
while task-relevant changes may occur both in the observation gaps and during
the ensuing navigation, without being seen by the robot. We instantiate this
setting through portable-object navigation: given a target, a causal
observation history, candidate locations, and a finite action budget, the agent
must locate the target without access to hidden transitions or the current
ground-truth state. The main protocol holds the target fixed after the query,
isolating inference across the preceding observation gap; an online-dynamic
extension permits further hidden changes during execution. This separation
makes the interaction between memory, prediction, and search measurable without
conflating it with continuous target tracking.

Our central insight is that history should support two distinct questions:
\emph{does the last observed state still hold, and if not, where might the
object be?} Their answers should remain probabilistic until physical evidence
resolves the uncertainty. This separates persistence from relocation while
retaining both as actionable hypotheses. It also gives observations a precise
role: a clear view of an empty candidate location should reduce its
probability, whereas an obstructed view should leave substantial uncertainty.
Prediction supplies an informed starting belief; navigation tests and revises
it as the world evolves.

We implement this principle in \evolvingworldnav{}, an embodied agent with
\textbf{4D Predictive Memory} (\cref{fig:evolvingworldnav_overview}). Its
memory associates persistent 3D entities with timestamped state histories and
observation provenance. The predictive core, \pfdnav{}, encodes irregular
observations with a continuous-time Transformer and factorizes the current-state
belief into a persistence probability and a distribution over relocation
candidates. A frozen vision--language controller accesses this learned
predictor through typed tools. The agent orders inspections using candidate
probability, expected visibility, and travel cost, then applies
visibility-aware Bayesian updates after each observation and replans. Newly
acquired observations return to memory, closing the loop between historical
evidence, current-state inference, and action.

To evaluate this loop, we introduce \pfdbench{}, a human-trace-grounded
simulation benchmark containing 54 scenes and 803.68k task instances across
state prediction, object navigation, vision-and-language navigation, and
embodied question answering. Paired static, routine, and random worlds control
scene and query factors while varying the hidden transition process. Our
primary experiments focus on current-state prediction and navigation.
\evolvingworldnav{} achieves 61.32\% First-Go SR and 86.18\% Search SR,
improving over DynaMem, the strongest baseline on both metrics, by 15.99 and
5.18 percentage points (\cref{tab:crossbench}). Additional evaluations on
FindingDory, GOAT-Bench, held-out scenes, and physical robots examine transfer
beyond the primary benchmark. The paired controls show the clearest gain when
hidden changes follow learnable routines; performance on random transitions is
lower, indicating that predictive memory is most useful when histories contain
reusable temporal structure (\cref{tab:worlds}).

\paragraph{Contributions.}
\begin{itemize}[leftmargin=5mm,itemsep=0.6mm,topsep=1mm]
    \item \textbf{A controlled setting for navigation from evolving state.}
    We formulate portable-object navigation across observation gaps and during
    further hidden evolution, separating prediction, search, and recovery from
    continuous target tracking.
    \item \textbf{A structured predictive-memory agent.} We introduce
    \evolvingworldnav{}, which couples a learned persistence--relocation belief
    with cost-aware inspection and visibility-aware evidence updates under a
    frozen vision--language controller.
    \item \textbf{A benchmark for hidden world evolution.} We introduce
    \pfdbench{} with causal observation histories and paired
    static/routine/random controls to test when temporal prediction improves
    embodied decisions.
\end{itemize}
