\section{DR-AgentOS}
\label{sec:method}

\subsection{Problem Setting and System Loop}

At decision round $t$, the agent receives the available subset of RGB image $\mathbf I_t$, depth $\mathbf D_t$, geometric observation $\mathbf L_t$, robot pose $\boldsymbol\xi_t$, and timestamp $\tau_t$. Given natural-language task $\mathcal T$, execution state $\mathbf s_t$, active task stage $\rho_t$, callable tools $\mathcal Z$, and persistent memory $\mathcal M_t$, the controller constructs a task-conditioned query and selects a tool call:
\begin{align}
\mathbf q_t &= \mathcal Q(\mathcal T,\rho_t,\mathbf s_t), \\
(z_t,\mathbf a_t) &= \Pi\!\left(\mathcal T,\rho_t,\mathbf s_t,
\mathcal R(\mathcal M_t,\mathbf q_t),\mathcal Z\right).
\label{eq:controller}
\end{align}
The controller then verifies execution against explicit completion conditions, detects conflicts with existing memory, gathers evidence when needed, and applies a gated update. This yields a closed perception--memory--reasoning--action--reflection loop rather than a one-shot perception-to-action pipeline.

\subsection{Evidence-Grounded 4D World Memory}

\paragraph{Direct semantic projection.}
For pixel $\widetilde{\mathbf u}=[u,v,1]^\top$ with valid depth, the corresponding world point is
\begin{equation}
\mathbf x^w=\operatorname{proj}_3\!\left(\mathbf T_{w\leftarrow c,t}
\begin{bmatrix}D_t(u,v)\mathbf K^{-1}\widetilde{\mathbf u}\\1\end{bmatrix}\right),
\label{eq:backprojection}
\end{equation}
where $\mathbf K$ is the camera intrinsic matrix and $\mathbf T_{w\leftarrow c,t}$ the camera-to-world transform. Semantic regions from open-vocabulary perception are lifted directly into this frame. Cross-view consolidation uses semantic compatibility, 3D proximity, temporal consistency, and source confidence, so repeated observations strengthen a persistent entity rather than create disconnected detections.

\paragraph{Causal, versioned memory.}
Memory at time $t$ is materialized only from past and current evidence,
\begin{equation}
\mathcal M_{\leq t}=\operatorname{Materialize}(\Delta\mathcal M_0,\ldots,\Delta\mathcal M_t)
=(\mathcal G_{\leq t},\mathbb T_{\leq t},\mathcal B_{\leq t}),
\label{eq:memory}
\end{equation}
where $\mathcal G$ is a semantic-spatial graph, $\mathbb T$ a set of world-state segments, and $\mathcal B$ an evidence/provenance bank. An entity has a stable identity $i$, semantic label $\ell_i$, geometry $\mathbf p_i$, relations $\mathcal N_i$, and a pointer to its current version. Its $k$-th state version is
\begin{equation}
h_i^k=([\tau_{i,s}^k,\tau_{i,e}^k),y_i^k,c_i^k,\mathbf f_i^k,\mathcal P_i^k),
\label{eq:version}
\end{equation}
containing a validity interval, structured state, confidence, visual features, and provenance. Stable identity is therefore separated from mutable state: a door remains the same entity when its accessibility changes, and an object may move without losing its history. The graph follows a Timeline--Floor--Room--Object hierarchy and retains metric, containment, proximity, and connectivity relations. Assertions link back to sensor time, source pose, visual support, and confidence.

\subsection{Task-Conditioned Multimodal Retrieval}

Each entity's retrieval record contains its current description, object crop, full-frame context, mapper-owned coordinate, source pose, and provenance. The query is encoded against three semantic channels---description, crop, and context---and ranked independently. For normalized query embedding $\mathbf z_q$ and entity representation $\mathbf z_i^{(m)}$,
\begin{equation}
s_i^{(m)}=\langle\mathbf z_q,\mathbf z_i^{(m)}\rangle,
\qquad m\in\{\mathrm{desc},\mathrm{crop},\mathrm{ctx}\}.
\end{equation}
We combine ranks rather than raw scores because channel scales need not be calibrated. Weighted Reciprocal Rank Fusion gives
\begin{equation}
S_i^{\mathrm{RRF}}=\sum_{m\in\mathcal M_q}\frac{w_m}{K_{\mathrm{RRF}}+r_i^{(m)}},
\label{eq:rrf}
\end{equation}
with $K_{\mathrm{RRF}}=60$ and default weights $(1.0,1.0,0.5)$ for description, crop, and context.

\paragraph{Relation-aware QueryGraph.}
Relational instructions are parsed into a target, an anchor, and a supported spatial predicate. For a \texttt{near} relation, target $i$ and anchor $a$ receive
\begin{equation}
S_{i,a}^{\mathrm{spatial}}=\alpha/r_a^{\mathrm{sem}}+(1-\alpha)/(1+\|\mathbf p_i^{xy}-\mathbf p_a^{xy}\|_2),
\label{eq:relation}
\end{equation}
where $\alpha=0.45$. The best compatible anchor supplies a relation rank that enters \cref{eq:rrf}. Unsupported parses fail closed to the three-channel retrieval path.

\paragraph{Constrained VLM resolution.}
The top-$K$ candidates are presented with their evidence. The VLM must return \texttt{confirmed}, \texttt{ambiguous}, or \texttt{not\_found}; a confirmed identifier must belong to the presented set $\mathcal C_q$, otherwise it is rejected. Crucially, confirmation binds the semantic goal to the coordinate already stored by memory,
\begin{equation}
\widehat i\in\mathcal C_q\ \text{or}\ \widehat i=\varnothing,
\qquad \mathbf g_{\mathrm{sem}}=\mathbf p_{\widehat i}.
\label{eq:binding}
\end{equation}
The VLM selects among evidence-backed identities but cannot invent an entity or modify geometry. If evidence is insufficient, the controller can retrieve history, broaden context, acquire a new view, and re-rank within a fixed budget.

\subsection{Typed Tools and Closed-Loop Execution}

Natural language is normalized into goal $G$, constraints $\Omega$, completion predicate $\chi$, and a subtask dependency graph. Each tool declares a name, typed input schema, permitted controller modes, and schema version; each result returns execution status, structured payload, evidence handles, latency, and a normalized error. The registry validates tool existence, mode, arguments, and call budget before dispatch. This interface separates probabilistic reasoning from authoritative components: mapping owns entity identities and coordinates, workers own deterministic algorithmic outputs, the runtime owns pose and collision feedback, and verification owns state commit.

For navigation, an object coordinate may lie in occupied space, so the planner snaps it to the nearest cell in the robot's reachable free component $\mathcal R_t$:
\begin{equation}
g'=\arg\min_{v\in\mathcal R_t}\|v-g\|_2^2.
\label{eq:snap}
\end{equation}
An 8-connected weighted distance field selects a short-term goal with minimum remaining geodesic distance. Only one action is issued before updated pose and collision evidence trigger replanning. Thus a successful planning call is distinct from a verified physical outcome.

\subsection{Conflict-Aware Reflection and Update}

New evidence is compared with current memory along state, position, visibility-aware absence, and topology dimensions. A missing detection counts as evidence of disappearance only if the remembered location should be visible given pose, field of view, occlusion, and sensing conditions. Material conflicts cause the controller to retrieve history, change viewpoint, repeat perception, inspect a route, or seek clarification.

For proposed state $\widehat h_{i,t}$, let evidence item $b$ have reliability $r_b$, agreement $a_b$, and source-dependent weight $w_b$. Corroboration is
\begin{equation}
C_{\mathrm{evidence}}=\frac{\sum_{b\in\mathcal B_t(i)}w_b r_b a_b}{\sum_{b\in\mathcal B_t(i)}w_b+\epsilon}.
\end{equation}
A persistent update is committed only when the conflict has been examined and the score exceeds an entity-dependent threshold:
\begin{equation}
g_t(i)=\mathbb I[C_{\mathrm{evidence}}\geq\eta_i\ \land\ r_t^{\mathrm{conf}}(i)=1].
\label{eq:gate}
\end{equation}
When the gate is closed, evidence remains provisional; when open, the new state is appended as a version and the current pointer advances. Earlier versions are never overwritten. This design preserves uncertain observations for later reasoning without promoting them prematurely to durable facts.
