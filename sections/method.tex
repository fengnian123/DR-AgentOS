\section{Predictive 4D Belief Navigation}
\label{sec:method}

\subsection{Persistent Navigation in Evolving Worlds}
\label{sec:problem}

We study portable-object navigation to isolate the coupling between hidden world
change, predictive belief, and physical action. Each target $o$ has candidate
states $\mathcal C_o$, consisting of semantically valid receptacles or regions
with inspection viewpoints. At query time $t_q$, the agent receives a target,
start pose, action budget, and causal RGB-D history
$\mathcal H_{\leq t_q}=\{(I_k,D_k,\xi_k,t_k):t_k\leq t_q\}$, where $\xi_k$
is camera pose. The current state
$s_q^o\in\mathcal C_o\cup\{\mathrm{unknown}\}$ is hidden. Success requires
stopping near a valid viewpoint with the target visible; the objective also
penalizes travel and unnecessary inspections (\cref{eq:objective}).
The main protocol freezes the target after the query, testing inference from
stale history. The online-dynamic extension advances the clock during execution
and may introduce a further hidden transition outside the camera view.
Both use the architecture in \cref{fig:p4dnav_method}.

\subsection{From Causal 4D Memory to Current-State Belief}
\label{sec:belief_model}

\paragraph{Evidence-grounded memory.}
Timestamped RGB-D observations are registered in a shared 3D frame and associated
across views using semantics, geometry, temporal consistency, and source
confidence. Frozen open-vocabulary perception supplies semantic evidence
\citep{liu2024grounding,ravi2025sam,radford2021learning}. Persistent entity
identity is separated from mutable state: changes append time-valid versions
without erasing earlier observations. Query-time memory excludes all evidence
after $t_q$ and retains observation provenance (\cref{app:memory-details}).
For each target, a typed query retrieves up to $K$ events
$H_o=\{(o_k,s_k,t_k,z_k,c_k,v_k)\}_{k=1}^{K}$, recording entity, candidate
state, time, positive or negative evidence, perception confidence, and visibility.
Related context events are allowed, but hidden activities and transition labels
are excluded. Candidates encode context, functional role, geometry, and instance
identity; \texttt{unknown} absorbs states outside the mapped set.

\paragraph{Continuous-time persistence--relocation belief.}
Event tokens combine these fields with elapsed time $t_q-t_k$ and sinusoidal
hour-of-day and day-of-week features. A query token specifies the target, query
time, and last positive state. A compact continuous-time Transformer produces
query representation $\mathbf h_q$, modeling irregular observation gaps and
event order without oracle mobility labels. We separate whether the last
positive state $s_{\mathrm{last}}$ persists from where the target relocated:
\begin{equation}
\rho_q=\sigma(\mathbf w_\rho^\top\mathbf h_q),\qquad
b_q^-(i)=
\begin{cases}
\rho_q, & i=s_{\mathrm{last}},\\
(1-\rho_q)\pi_q(i), & i\neq s_{\mathrm{last}},
\end{cases}
\label{eq:prior}
\end{equation}
where $\rho_q=P(s_q^o=s_{\mathrm{last}}\mid H_o,t_q)$ and $\pi_q$ is a
shared pointer head normalized over alternative candidates. Training minimizes
$\mathcal L_{\mathrm{state}}=-\log b_q^-(s_q^o)$ without oracle change
labels. The factorization can preserve a valid last state, concentrate on
recurring transitions, or expose diffuse uncertainty to the agent. Token and
pointer definitions appear in \cref{app:belief-parameterization}.

\subsection{Predictive Embodied Agent}
\label{sec:agent}

A frozen high-level vision--language controller resolves the goal and invokes
typed memory, prediction, navigation, and inspection tools. Observations and
posteriors are written back to causal memory. In controlled comparisons,
methods share the perception stack and low-level navigator, isolating
differences in belief and evidence gathering.

\paragraph{Cost-aware inspection.}
For candidate $i$, let $\mathcal W_i$ be its reachable inspection viewpoints,
$d(x,\mathcal W_i)$ the shortest geodesic distance from the current pose, and
$\widehat v_i$ expected inspection coverage. The agent selects
\begin{equation}
i^*=\arg\max_{i\in\mathcal C_o\setminus\mathcal I}
\frac{b(i)\widehat v_i}{d(x,\mathcal W_i)+\lambda_{\mathrm{inspect}}},
\label{eq:planner}
\end{equation}
where $b$ is the current belief, $\lambda_{\mathrm{inspect}}$ is the inspection
cost, and $\mathcal I$ contains sufficiently inspected hypotheses. Concentrated
belief supports direct navigation; diffuse belief induces cost-aware search.
The navigator returns RGB-D evidence rather than a privileged success flag.

\paragraph{Visibility-aware updates.}
An inspection at candidate $r$ yields result $z$, detector reliability $c$, and
effective visibility $v\in[0,1]$. For negative evidence, the likelihood is
$P(z=\mathrm{notseen}\mid s_q^o=r,c,v)=1-cv$, and is $1$ elsewhere.
The posterior is
\begin{equation}
b_q^+(i)=\frac{b_q^-(i)P(z\mid s_q^o=i,c,v)}
{\sum_j b_q^-(j)P(z\mid s_q^o=j,c,v)}.
\label{eq:bayes}
\end{equation}
A positive instance match supports $r$; a clear empty view suppresses it, whereas
an occluded view only weakly changes the belief. The agent records this evidence,
removes only sufficiently tested hypotheses, and replans until success, budget
exhaustion, or \texttt{NOT\_FOUND}. For online-dynamic episodes, it predicts
arrival-time belief
$b^-_{t+\widehat\tau_i}=F_\theta(H_o,t+\widehat\tau_i)$, where $F_\theta$ is
the learned predictor and $\widehat\tau_i$ is estimated travel time, and
replans after every action chunk. Direct navigation, search, and recovery share one
loop, without an explicit static/dynamic policy router.
