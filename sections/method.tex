\section{Predictive 4D Belief Navigation}
\label{sec:method}

\subsection{Persistent Dynamic Object Navigation}
\label{sec:problem}

Let an environment contain a navigable space $\mathcal X$, a set of persistent entities $\mathcal O$, and candidate object states $\mathcal C_o$ for each target $o\in\mathcal O$. A state identifies a semantically valid receptacle or region and its associated inspection viewpoints. Before a query at time $t_q$, the agent has collected only a partial history
\begin{equation}
\mathcal H_{\leq t_q}=\{(I_k,D_k,\xi_k,t_k)\mid t_k\leq t_q\},
\end{equation}
where $I_k,D_k,\xi_k$ denote RGB, depth, and camera pose. The target's true query-time state $s_q^o\in\mathcal C_o\cup\{\mathrm{unknown}\}$ and any unobserved transition events are hidden.

An episode supplies a target description, query time, initial agent pose $x_0$, a causal memory materialized from $\mathcal H_{\leq t_q}$, and a finite action budget. At decision step $j$, the agent chooses a candidate viewpoint or a low-level navigation action, receives an observation $z_j$, and may terminate with \texttt{STOP} or \texttt{NOT\_FOUND}. Success requires a correct stop near a valid goal viewpoint with the target visible. The policy should maximize success while minimizing travelled distance and inspections:
\begin{equation}
\pi^*=\arg\max_{\pi}\;\mathbb E_{\pi}\!\left[
\mathbb I(\mathrm{success})-\lambda_d L-\lambda_n N_{\mathrm{inspect}}
\right].
\label{eq:objective}
\end{equation}
The main protocol holds the target fixed after $t_q$, isolating whether a stale history can be transformed into a useful current belief. The online-dynamic extension advances the world clock during execution and may apply an additional transition while the target is outside the camera view.

\subsection{Evidence-Grounded 4D Memory}
\label{sec:memory}

The 4D memory represents a persistent 3D semantic scene whose entity states evolve over time. For image coordinate $\widetilde{\mathbf u}=[u,v,1]^\top$ with depth $D_t(u,v)$, the corresponding world point is
\begin{equation}
\mathbf x^w=\operatorname{proj}_3\!\left(
\mathbf T_{w\leftarrow c,t}
\begin{bmatrix}D_t(u,v)\mathbf K^{-1}\widetilde{\mathbf u}\\1\end{bmatrix}
\right),
\label{eq:backprojection}
\end{equation}
where $\mathbf K$ is the camera intrinsic matrix and $\mathbf T_{w\leftarrow c,t}$ is the camera-to-world transform. Cross-view association consolidates observations using semantic compatibility, 3D overlap, temporal consistency, and source confidence. Repeated observations strengthen one persistent entity rather than creating disconnected detections.

Memory is materialized causally from versioned deltas:
\begin{equation}
\mathcal M_{\leq t}=\operatorname{Materialize}(\Delta\mathcal M_0,\ldots,\Delta\mathcal M_t)
=(\mathcal G_t,\mathcal V_t,\mathcal B_t),
\label{eq:memory}
\end{equation}
where $\mathcal G_t$ stores semantic and spatial relations, $\mathcal V_t$ stores time-valid entity versions, and $\mathcal B_t$ stores observation provenance. The $m$-th version of entity $o$ is
\begin{equation}
h_o^m=([t_{o,s}^m,t_{o,e}^m),\,s_o^m,\,c_o^m,\,f_o^m,\,\mathcal P_o^m),
\end{equation}
containing a validity interval, candidate state, confidence, visual feature, and evidence handles. Persistent identity is separated from mutable state: moving an object appends a version without erasing its earlier trajectory. All query-time views exclude observations and events after $t_q$.

\subsection{Target-Conditioned History Retrieval}
\label{sec:retrieval}

For a target $o$, the retriever first resolves its persistent identity or category-compatible instances, then returns the most recent $K$ causal events
\begin{equation}
H_o=\{e_k=(o_k,s_k,t_k,z_k,c_k,v_k)\}_{k=1}^{K}.
\label{eq:history}
\end{equation}
Here $s_k$ is the observed candidate state; $z_k\in\{\mathrm{seen},\mathrm{notseen}\}$ is the evidence type; $c_k$ is perception confidence; and $v_k$ summarizes whether the hypothesized state was adequately visible, including frustum coverage and unoccluded fraction. Context events may be included when they share an entity, receptacle, region, or time window with the target, but hidden activity labels are never exposed at test time.

Candidates $i\in\mathcal C_o$ are not global class indices. Each is encoded from its region, receptacle category, functional role, geometry, and instance identity. This pointer-compatible representation permits the number and identity of states to vary across homes and supports evaluation on unseen receptacle instances. An additional \texttt{unknown} candidate absorbs states outside the mapped set.

\subsection{Continuous-Time History Encoder}
\label{sec:encoder}

Each event token combines entity, state, evidence, confidence, and visibility embeddings with an explicit encoding of elapsed and calendar time:
\begin{align}
\mathbf x_k={}&E_o(o_k)+E_s(s_k)+E_z(z_k)+E_c(c_k)+E_v(v_k)\\
&+\phi_{\Delta}(t_q-t_k)+\phi_{\mathrm{cal}}(t_k),
\label{eq:eventtoken}
\end{align}
where $\phi_{\Delta}$ includes $\log(1+t_q-t_k)$ and $\phi_{\mathrm{cal}}$ contains sinusoidal hour-of-day and day-of-week features. A learned query token specifies the target, query time, and last positively observed state. A small Transformer produces contextual event features and query representation
\begin{equation}
(\mathbf h_1,\ldots,\mathbf h_K,\mathbf h_q)
=\operatorname{CTTransformer}(\mathbf x_1,\ldots,\mathbf x_K,\mathbf x_q).
\end{equation}
Unlike a fixed time-bin transition table, this encoder conditions on irregular gaps, repeated negative evidence, and the complete order of observed states. It does not receive oracle mobility type or the activity that generated a hidden transition.

\subsection{Persistence--Relocation Belief}
\label{sec:belief}

A direct classifier entangles two physically distinct questions: whether anything changed and where the object went. We instead factorize them. Let $s_{\mathrm{last}}$ be the last positive state. The persistence branch predicts
\begin{equation}
\rho_q=P(s_q^o=s_{\mathrm{last}}\mid H_o,t_q)
=\sigma(\mathbf w_{\rho}^{\top}\mathbf h_q).
\label{eq:persistence}
\end{equation}
For every relocation candidate $i\neq s_{\mathrm{last}}$, a shared pointer head computes
\begin{equation}
a_i=\frac{(W_q\mathbf h_q)^\top(W_c\mathbf g_i)}{\sqrt d}
+\psi(\mathbf h_q,\mathbf g_i),\qquad
\pi_q(i)=\frac{\exp a_i}{\sum_{j\neq s_{\mathrm{last}}}\exp a_j},
\label{eq:pointer}
\end{equation}
where $\mathbf g_i$ is the candidate representation and $\psi$ captures target--candidate compatibility. The prior belief is
\begin{equation}
b_q^-(i)=
\begin{cases}
\rho_q, & i=s_{\mathrm{last}},\\
(1-\rho_q)\pi_q(i), & i\neq s_{\mathrm{last}}.
\end{cases}
\label{eq:prior}
\end{equation}
The model is trained end-to-end with a single negative log-likelihood,
$\mathcal L_{\mathrm{state}}=-\log b_q^-(s_q^o)$. The factorization is therefore an inductive bias, not a separately supervised oracle switch. In static environments it can place mass on persistence; for recurring relocations it can concentrate $\pi_q$; and for irregular objects it can retain a broad distribution.

\subsection{Visibility-Aware Bayesian Evidence Update}
\label{sec:update}

After navigating to candidate $r$, the agent obtains detection result $z$, detector reliability $c$, and effective visibility $v\in[0,1]$. A positive instance match assigns high likelihood to $r$. A negative observation should suppress $r$ only if the target would probably have been detected there. We use
\begin{equation}
P(z=\mathrm{notseen}\mid s_q^o=i,c,v)=
\begin{cases}
1-cv, & i=r,\\
1, & i\neq r,
\end{cases}
\label{eq:negative}
\end{equation}
followed by
\begin{equation}
b_q^+(i)=\frac{b_q^-(i)P(z\mid s_q^o=i,c,v)}
{\sum_j b_q^-(j)P(z\mid s_q^o=j,c,v)}.
\label{eq:bayes}
\end{equation}
Thus, a clear empty view provides strong negative evidence, whereas an occluded or poorly covered view makes only a small change. The update is parameter free and can be applied repeatedly. Each inspection and its posterior are written back as a provisional memory event, preserving the causal chain used by subsequent decisions.

\subsection{Belief-Guided Navigation and Replanning}
\label{sec:planner}

Each candidate $i$ has one or more reachable inspection viewpoints $\mathcal W_i$. Let $d(x,\mathcal W_i)$ be the shortest geodesic distance from the current pose and $\widehat v_i$ the expected inspection coverage. The high-level policy selects
\begin{equation}
i^*=\arg\max_{i\in\mathcal C_o\setminus\mathcal I}
\frac{b(i)\widehat v_i}
{d(x,\mathcal W_i)+\lambda_{\mathrm{inspect}}},
\label{eq:planner}
\end{equation}
where $\mathcal I$ contains sufficiently inspected hypotheses. The fixed low-level navigator executes the route and the evidence update in \cref{eq:bayes} produces the belief for the next decision. This separation ensures that gains reflect memory and state selection rather than a different locomotion controller.

The same interface instantiates three core tasks. \emph{Predictive Object Navigation} executes only the top-belief candidate and measures first-go success. \emph{Belief-Guided Object Search} follows the probability--cost policy under a candidate budget. \emph{Evidence-Aware Replanning} updates after every qualified view and measures recovery from an incorrect first prediction. For online-dynamic episodes, the model is queried at the candidate arrival time $t+\widehat\tau_i$ rather than the current time:
\begin{equation}
b_{t+\widehat\tau_i}^-=F_\theta(H_o,t+\widehat\tau_i),
\end{equation}
and replanning repeats after every action chunk. No explicit router chooses between ``static'' and ``dynamic'' policies; their behavior is induced by the learned belief and the evidence observed during navigation.
