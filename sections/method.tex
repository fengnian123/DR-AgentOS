\section{Predictive 4D Belief Navigation}
\label{sec:method}

\evolvingworldnav{} turns timestamped 3D histories into a current-state belief
and revises it using opportunistic and deliberate RGB-D evidence. Its \pfdnav{}
core separates persistence from relocation (\cref{fig:p4dnav_method}).
The resulting loop treats navigation as sequential belief revision: predictions
propose destinations, while embodied observations determine whether to continue,
redirect, or explore.

\subsection{Problem Formulation}
\label{sec:problem}

We formalize portable-object navigation to connect hidden world evolution,
predictive belief, and physical action. Let an environment contain a
navigable space $\mathcal X$, persistent entities $\mathcal O$, and candidate
states $\mathcal C_o$ for each target $o\in\mathcal O$. Each state is a valid
receptacle or region with inspection viewpoints. Before query time $t_q$, the
agent has collected only a partial history
\begin{equation}
\mathcal H_{\leq t_q}=\{(I_k,D_k,\xi_k,t_k)\mid t_k\leq t_q\},
\end{equation}
where $I_k,D_k,\xi_k$ denote RGB, depth, and camera pose. The true query-time
state $s_{t_q}^o\in\widetilde{\mathcal C}_o$ is hidden, where
$\widetilde{\mathcal C}_o=\mathcal C_o\cup\{\mathrm{unknown}\}$ includes
unmapped states. Later transitions outside the agent's view are also hidden.

An episode provides a target, query time, initial pose $x_0$, causal memory,
and a finite action budget. At step $j$, the agent acts and observes $z_j$;
success requires stopping near a valid viewpoint with the target visible and
correctly identified.
The objective is
\begin{equation}
\pi^*=\arg\max_{\pi}\;\mathbb E_{\pi}\!\left[
\mathbb I(\mathrm{success})-\lambda_d L-\lambda_n N_{\mathrm{inspect}}
\right],
\label{eq:objective}
\end{equation}
where $L$ is travel distance, $N_{\mathrm{inspect}}$ counts inspections, and
$\lambda_d,\lambda_n$ weight their costs. \pfdbench{} provides complementary
protocols: N1--N3 hold the target fixed during navigation to isolate query-time
inference and evidence-guided search, whereas N4 permits further hidden
transitions while the agent moves. Both use the same event-driven filtering and
replanning interface.

\subsection{Causal 4D Memory and History Encoding}
\label{sec:memory_encoding}
The 4D memory registers RGB-D observations in a shared frame and associates
persistent entities across views using semantics, geometry, time, and source
confidence. Frozen open-vocabulary models provide semantic support
\citep{liu2024grounding,ravi2025sam,radford2021learning}. Memory is materialized
causally from versioned deltas:
\begin{equation}
\mathcal M_{\leq t}=\operatorname{Materialize}(\Delta\mathcal M_0,\ldots,\Delta\mathcal M_t)
=(\mathcal G_t,\mathcal V_t,\mathcal B_t),
\label{eq:memory}
\end{equation}
where $\mathcal G_t$ stores semantic--spatial relations, $\mathcal V_t$ stores
time-valid entity versions, and $\mathcal B_t$ stores observation provenance.
An observed change appends a time-valid version without erasing identity or
history, and every query excludes future evidence. Projection, association, and
versioning details appear in \appref{app:memory-details}.

\paragraph{Target-conditioned history and continuous time.}
For target $o$, a typed memory query resolves its persistent identity and returns
the most recent $K$ causal events
\begin{equation}
H_o=\{e_k=(o_k,s_k,t_k,z_k,c_k,v_k)\}_{k=1}^{K},
\label{eq:history}
\end{equation}
where $o_k,t_k$ denote the entity and observation time;
$s_k$ identifies the observed or inspected candidate state;
$z_k\in\{\mathrm{seen},\mathrm{notseen}\}$ is the evidence type; $c_k$ is
perception confidence; and $v_k$ measures whether that state was adequately
visible. Context events share entities, receptacles, regions, or time windows
with the target; hidden labels are excluded. Candidate encodings combine
context, function, geometry, and identity, while \texttt{unknown} absorbs
unmapped states.

Each event token combines semantic, evidence, and temporal features:
\begin{align}
\mathbf x_k={}&E_o(o_k)+E_s(s_k)+E_z(z_k)+E_c(c_k)+E_v(v_k)\nonumber\\
&+\phi_{\Delta}(t_q-t_k)+\phi_{\mathrm{cal}}(t_k),
\label{eq:eventtoken}
\end{align}
where $\phi_{\Delta}$ includes $\log(1+t_q-t_k)$, $\phi_{\mathrm{cal}}$ encodes
hour and weekday, and a query token specifies the target, time, and last state.
A compact Transformer yields
\begin{equation}
(\mathbf h_1,\ldots,\mathbf h_K,\mathbf h_q)
=\operatorname{CTTransformer}(\mathbf x_1,\ldots,\mathbf x_K,\mathbf x_q).
\label{eq:history-encoder}
\end{equation}
This captures irregular gaps, negative evidence, and event order without hidden
labels.

\subsection{Persistence--Relocation Belief}
\label{sec:belief_model}
We predict whether the last observed state still holds and, if not, where the
target is. Let $s_{\mathrm{last}}$ be the last positive state, guaranteed by
episode validity (\appref{app:audit}). The persistence branch predicts
\begin{equation}
\rho_q=P(s_{t_q}^o=s_{\mathrm{last}}\mid H_o,t_q)
=\sigma(\mathbf w_{\rho}^{\top}\mathbf h_q).
\label{eq:persistence}
\end{equation}
For each alternative $i\in\widetilde{\mathcal C}_o\setminus
\{s_{\mathrm{last}}\}$, a shared pointer head computes
\begin{equation}
a_i=\frac{(W_q\mathbf h_q)^\top(W_c\mathbf g_i)}{\sqrt d}
+\psi(\mathbf h_q,\mathbf g_i),\qquad
\pi_q(i)=\frac{\exp a_i}{\sum_{u\in\widetilde{\mathcal C}_o\setminus\{s_{\mathrm{last}}\}}\exp a_u},
\label{eq:pointer}
\end{equation}
where $\mathbf g_i$ represents candidate $i$, $d$ is the projection dimension,
and $\psi$ measures learned compatibility. The prior is
\begin{equation}
b_q^-(i)=
\begin{cases}
\rho_q, & i=s_{\mathrm{last}},\\
(1-\rho_q)\pi_q(i), & i\neq s_{\mathrm{last}}.
\end{cases}
\label{eq:prior}
\end{equation}
We train with $\mathcal L_{\mathrm{state}}=-\log b_q^-(s_{t_q}^o)$, without
change labels. The factorization represents returns to the last state,
recurring alternatives, and diffuse uncertainty in one normalized belief.

\subsection{Predictive Embodied Agent}
\label{sec:agent}

Given a goal, a frozen vision--language controller invokes memory, prediction,
navigation, inspection, and exploration tools. An event-driven
predict--observe--replan filter runs after a short action chunk or when new
coverage is sufficient, the ETA or route changes substantially, target evidence
is observed, or the agent reaches an inspection viewpoint. En-route evidence can
therefore redirect the first deliberate inspection rather than only affect
later recovery.

\paragraph{Arrival-aware action selection.}
For candidate viewpoints $\mathcal W_i$, let
$d_{j,i}=d_{\mathrm{geo}}(x_j,\mathcal W_i)$ and $\widehat\tau_{j,i}$ be
geodesic distance and estimated arrival-plus-inspection time. The agent selects
\begin{equation}
i_j^*=\arg\max_{i\in\mathcal{C}_o}
\frac{
    p_{j,i}^{\mathrm{arr}}\,
    \widehat{q}_{j,i}^{\,\mathrm{new}}
}{
    d_{j,i}
    + \lambda_t \widehat{\tau}_{j,i}
    + \lambda_{\mathrm{inspect}}
},
\label{eq:planner}
\end{equation}
where $p_{j,i}^{\mathrm{arr}}$ comes from \cref{eq:arrival-belief} and
$\widehat q_{j,i}^{\mathrm{new}}$ is detection probability from unseen
coverage. If unknown-state exploration has higher utility, the agent scans an
uncovered region and expands the candidate set.

\paragraph{Visibility-qualified measurement update.}
A posed RGB-D view can update every covered candidate. The agent estimates
$\widehat r_{j,i}=P(\mathrm{detect}\mid s_{t_j}=i,\mathbf f_{j,i})$ from
projected candidate geometry, online depth, and calibrated view features,
without target masks, poses, or simulator visibility flags. Given no detection,
\begin{equation}
\ell_j(i)=P(y_j=\varnothing\mid s_{t_j}=i)=
\begin{cases}
1-\widehat r_{j,i}, & i\in\mathcal C_o,\\
1, & i=\mathrm{unknown},
\end{cases}
\label{eq:negative}
\end{equation}
and the measurement posterior is
\begin{equation}
b_j^+(i)=\frac{b_j^-(i)\ell_j(i)}
{\sum_{u\in\widetilde{\mathcal C}_o}b_j^-(u)\ell_j(u)}.
\label{eq:bayes}
\end{equation}
The update is applied only when cumulative coverage increases by more than
$\delta_C=0.05$, preventing correlated-frame reuse. The agent stops after a
verified match.

\paragraph{Posterior propagation and replanning.}
Rather than restarting query-time prediction, \pfdnav{} propagates the latest
posterior through $[K_\theta^{(j)}(\Delta t)]_{r,u}=
P(s_{t_j+\Delta t}=u\mid s_{t_j}=r,\mathcal H_{\leq t_j})$:
\begin{equation}
b_{j,i}^{\mathrm{arr}}=b_j^+K_\theta^{(j)}(\widehat\tau_{j,i}),\qquad
p_{j,i}^{\mathrm{arr}}=b_{j,i}^{\mathrm{arr}}(i).
\label{eq:arrival-belief}
\end{equation}
N1--N3 use identity dynamics after the query; N4 propagates to each candidate's
ETA. Each measurement enters once, and its posterior is the next propagation
state. Transition mass or a new viewpoint can reopen an inspected candidate;
the agent replans when the preferred utility changes. Details on ETA,
de-duplication, reopening, and executable semantics for the unknown state appear
in \appref{app:belief-control}.
