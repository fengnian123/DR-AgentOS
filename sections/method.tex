\section{Predictive 4D Belief Navigation}
\label{sec:method}

\evolvingworldnav{} turns timestamped 3D histories into a belief over current object
locations, then tests and revises it through physical inspection
(\cref{fig:p4dnav_method}). Its predictive core, \pfdnav{}, separates
persistence from relocation.

\subsection{Problem Formulation}
\label{sec:problem}

For target $o$, $\mathcal C_o$ contains candidate locations with inspection
viewpoints; $\widetilde{\mathcal C}_o=\mathcal C_o\cup\{\mathrm{unknown}\}$
also covers unmapped states. At query time $t_q$, the agent receives a target
description, initial pose, action budget, and partial RGB-D history
$\mathcal H_{\leq t_q}=\{(I_k,D_k,\xi_k,t_k):t_k\leq t_q\}$, where $\xi_k$
is camera pose. The true state $s_{t_q}^o$ is hidden. Success requires a stop
near a valid viewpoint with the target visible and correctly identified.
The main protocol fixes the target after $t_q$; the online-dynamic extension
permits further hidden transitions during navigation (\cref{app:episode}).

\subsection{Causal 4D Memory and History Encoding}
\label{sec:memory_encoding}
Frozen perception models supply detections, masks, and features
\citep{liu2024grounding,ravi2025sam,radford2021learning}. RGB-D observations
are registered in a shared frame and associated across views using semantics,
geometry, temporal consistency, and source confidence.
Memory stores semantic--spatial relations, time-valid entity versions, and
observation provenance. Persistent identities link successive versions; changes
append versions without overwriting history (\cref{app:memory-details}).
Memory queries use only evidence available at their decision time.

A target query retrieves the latest $K$ causal events
$H_o=\{(o_k,s_k,t_k,z_k,c_k,v_k)\}_{k=1}^K$: entity, candidate state, time,
evidence type ($\mathrm{seen}/\mathrm{notseen}$), confidence, and visibility.
Context may include related entities, receptacles, regions, and time windows,
but excludes hidden activities and transition labels. A continuous-time
Transformer combines these events with elapsed-time and calendar features.
The former include $\log(1+t_q-t_k)$; the latter use sinusoidal hour-of-day and
day-of-week encodings. A learned query token specifies the target, query time,
and last positive state; its Transformer output is $\mathbf h_q$. A shared
encoder represents each candidate's context, role, geometry, and identity
(\cref{app:belief-encoding}).

\subsection{Persistence--Relocation Belief}
\label{sec:belief_model}
Let $s_{\mathrm{last}}$ be the last positive state, guaranteed by episode
validity (\cref{app:audit}). A persistence head predicts its current probability
$\rho_q=\sigma(\mathbf w_\rho^\top\mathbf h_q)$. For alternatives
$i\in\widetilde{\mathcal C}_o\setminus\{s_{\mathrm{last}}\}$, a shared pointer
head computes
\begin{equation}
a_i=\frac{(W_q\mathbf h_q)^\top(W_c\mathbf g_i)}{\sqrt d}
+\psi(\mathbf h_q,\mathbf g_i),\qquad
\pi_q(i)=\frac{\exp a_i}
{\sum_{u\in\widetilde{\mathcal C}_o\setminus\{s_{\mathrm{last}}\}}\exp a_u},
\label{eq:pointer}
\end{equation}
where $\mathbf g_i$ represents candidate $i$, $d$ is the projection dimension,
and $\psi$ is a learned compatibility function. The prior is
\begin{equation}
b_q^-(i)=
\begin{cases}
\rho_q, & i=s_{\mathrm{last}},\\
(1-\rho_q)\pi_q(i), & i\neq s_{\mathrm{last}}.
\end{cases}
\label{eq:prior}
\end{equation}
We train the predictor end-to-end with $\mathcal L_{\mathrm{state}}=-\log b_q^-(s_{t_q}^o)$,
without separate change labels. Here $\rho_q$ measures current agreement with
the last observation, including departures followed by returns.

\subsection{Predictive Embodied Agent}
\label{sec:agent}

A frozen vision--language controller accesses memory, prediction, and navigation
through typed tools. It resolves the target and task constraints, selects inspections from the belief,
and updates it using returned RGB-D evidence.

\paragraph{Cost-aware inspection.}
For candidate $i$, let $\mathcal W_i$ denote reachable inspection viewpoints,
$d(x,\mathcal W_i)$ the shortest geodesic distance from pose $x$, and
$\widehat v_i$ the expected coverage. Given belief $b$, the agent selects
\begin{equation}
i^*=\arg\max_{i\in\mathcal C_o\setminus\mathcal I}
\frac{b(i)\widehat v_i}{d(x,\mathcal W_i)+\lambda_{\mathrm{inspect}}},
\label{eq:planner}
\end{equation}
where $\mathcal I$ contains sufficiently inspected hypotheses and
$\lambda_{\mathrm{inspect}}>0$ accounts for inspection cost. The
$\mathrm{unknown}$ state retains belief mass but has no inspection viewpoint.

\paragraph{Visibility-aware evidence updates.}
A verified target observation permits a successful stop. For a negative
inspection of $r_j$ at step $j$, we use detector reliability and visibility
$c_j,v_j\in[0,1]$ to define the likelihood and update
\begin{equation}
\ell_j(i)=
\begin{cases}
1-c_jv_j, & i=r_j,\\
1, & i\neq r_j,
\end{cases}
\qquad
b_j^+(i)=\frac{b_j^-(i)\ell_j(i)}
{\sum_{u\in\widetilde{\mathcal C}_o}b_j^-(u)\ell_j(u)}.
\label{eq:bayes}
\end{equation}
An empty, well-observed location loses probability; an occluded view provides
little counter-evidence. Initially $b_0^-=b_q^-$, and the fixed-target protocol
sets $b_{j+1}^-=b_j^+$. The agent records observations, visibility, and the inferred posterior, excludes
sufficiently tested hypotheses, and replans until success, budget exhaustion,
or \texttt{NOT\_FOUND}.

In online-dynamic episodes, the predictor $F_\theta$ evaluates arrival-time
beliefs $b_{t+\widehat\tau_i}^-=F_\theta(H_{o,\leq t},t+\widehat\tau_i)$,
where $\widehat\tau_i$ is estimated travel time and $H_{o,\leq t}$ includes
observations through the current decision time $t$. The agent replans after
each action chunk (\cref{app:belief-control}).
