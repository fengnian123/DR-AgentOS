First-Go SR is the cleanest measure of whether a more accurate current-state belief becomes a better physical destination. Search SR and cost then test whether probability mass beyond Top-1 is useful. Recovery SR is evaluated only on episodes in which the initial candidate was incorrect, preventing easy first-attempt successes from hiding poor replanning. The final analysis will report paired episode-level differences and confidence intervals rather than comparing only aggregate means.

\subsection{When Does Predictive Memory Help?}

Stable objects test backward compatibility: a predictive model should not damage a strong last-seen prior. Activity-routine objects test temporal transitions; personal-habit objects test long-term instance memory beyond global activity frequencies; and irregular objects test whether a broad, well-calibrated belief improves search even when Top-1 accuracy has limited headroom. The stratified result matrix is in \cref{tab:mobility}; we will additionally plot SR and excess path length against staleness to distinguish genuine temporal reasoning from memorized hotspots.

\subsection{Does the Gain Come from Learnable Dynamics?}

The paired-world matrix is reported in \cref{tab:worlds}. The expected signature is not uniformly high performance: \pfdnav{} should preserve static performance, gain most in routine worlds, and express greater uncertainty in marginal-matched random worlds. An improvement that remains unchanged after routine transitions are randomized would indicate a frequency, category, or route-length shortcut rather than learned dynamics.

\subsection{Ablations, Generalization, and Failure Analysis}

The final ablation table will jointly report state NLL and navigation cost, revealing whether a representation improves only classification or also changes useful decisions. In particular, we will compare query-time versus arrival-time belief on N4, prior-only versus Bayesian updating on N3, and structured versus direct heads on cross-scene candidates. Generalization results will separate seen-scene/unseen-household, unseen-scene/unseen-household, unseen object instance, and unseen receptacle instance.

Failures will be categorized as entity association, missing candidate, stale-state prediction, overconfident relocation, insufficient visibility, detector error, unreachable viewpoint, or replanning error. Qualitative trajectories will show the prior distribution, route, inspection coverage, posterior, and next decision at each step. This evidence is necessary to establish that improved navigation follows from the claimed closed-loop mechanism.
