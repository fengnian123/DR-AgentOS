\paragraph{Required analyses.}
The final empirical section should test more than aggregate QA quality. At minimum, it should ablate temporal versions, provenance-aware retrieval, relation rank, constrained VLM resolution, and evidence-gated updates; report retrieval recall before and after VLM verification; measure latency and memory growth; and stratify errors into retrieval failure, stale-state selection, relation failure, hallucinated resolution, and scoring mismatch. These tests directly correspond to the paper's system claims.
