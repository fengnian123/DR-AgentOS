\begin{abstract}
Embodied navigation is commonly formulated over a stationary world snapshot: maps and memories are assumed to describe the same state in which actions are executed. This abstraction breaks for long-lived agents. During periods without observation, objects are relocated, spaces are reconfigured, and accessibility changes, so historically valid evidence may induce obsolete goals and inefficient routes. We study \emph{persistent navigation in evolving worlds}, where an agent must infer the current task-relevant world state from partial and temporally stale observations, act under the resulting uncertainty, and revise its plan as physical evidence arrives. We introduce \dragentos{}, a predictive embodied-agent architecture whose navigation core, \pfdnav{}, transforms an evidence-grounded 4D memory into a belief over the current world state. A continuous-time Transformer encodes irregular histories, while a structured persistence--relocation pointer head estimates whether the last supported state remains valid and, otherwise, distributes probability over plausible alternatives. A visibility-aware Bayesian update converts positive and negative observations into posterior evidence, enabling direct navigation under concentrated belief, cost-aware exploration under uncertainty, and replanning when memory and observation disagree. We further introduce \pfdbench{}, a 54-scene, 90-scene-day benchmark with 803.68k tasks and 239.19k hidden state changes, spanning state prediction, object navigation, vision-and-language navigation, and embodied question answering. Paired static, routine, and random worlds isolate whether gains arise from learned dynamics rather than scene-frequency shortcuts. Together, \dragentos{} reframes embodied navigation from executing against a remembered snapshot to reasoning and acting over a continuously evolving world state.
\end{abstract}
