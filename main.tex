\begin{abstract}
Object navigation usually assumes that a target remains where it was mapped, yet a long-lived household agent often acts on observations that are hours or days old. Portable objects may move while unobserved, making the last-seen location an unreliable navigation goal. We study \emph{persistent dynamic object navigation}: an agent must locate an object from a partial, temporally stale history, gather physical evidence, and revise its route when memory and observation disagree. We introduce \pfdnav{}, which turns an evidence-grounded 4D memory into a predictive belief over the target's current state. A continuous-time Transformer encodes irregular observation histories, while a structured persistence--relocation pointer head separately estimates whether the last state remains valid and where the object moved otherwise. A visibility-aware Bayesian update converts positive and negative observations into posterior beliefs, enabling the same agent to navigate directly when belief is concentrated, search candidates when it is diffuse, and replan after failed inspections. We further introduce \pfdbench{}, a suite of paired HSSD navigation episodes whose hidden changes are compiled from complementary human activity, object-interaction, and household-state records. The benchmark controls scene, target, start pose, and candidate set across static, routine, and random worlds, isolating whether navigation gains arise from learnable dynamics rather than frequency shortcuts. Experiments evaluate predictive navigation, belief-guided search, evidence-aware recovery, online changes, and cross-scene generalization; numerical results are intentionally left blank in this working draft pending completion of the navigation rollouts.
\end{abstract}
