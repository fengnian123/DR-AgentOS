\begin{abstract}
Object-level memory enables robots to remember where objects were previously observed, but these locations can become outdated when objects are moved outside the robot’s view. Finding such objects requires reasoning about whether they remain at their last observed locations, where they may have moved, and where to search next. We propose \evolvingworldnav{}, an embodied agent for persistent object-goal navigation in evolving environments that transforms timestamped 3D entity histories into beliefs about current object locations. A continuous-time Transformer learns persistence and relocation patterns from irregular observations, estimating whether an object’s last observed location remains valid and where it is likely to be if relocated. Within a frozen vision–language control loop, the agent balances candidate-location probabilities against inspection costs to guide search. It then updates its beliefs and replans using visibility-aware evidence that distinguishes confirmed object absence from inconclusive views. To support evaluation of this task, we introduce \pfdbench{}, a human-trajectory-driven simulation benchmark comprising \textbf{54} scenes and \textbf{803.68k} task instances for evaluating reasoning and navigation under unobserved changes in object locations. In navigation evaluations, \evolvingworldnav{} achieves a first-attempt success rate of \textbf{61.32\%} and a search success rate of \textbf{86.18\%}, outperforming the strongest evaluated baseline by \textbf{15.99} and \textbf{5.18} percentage points, respectively. Controlled evaluations show that predictive gains are greatest when object movements exhibit learnable temporal structure, highlighting the importance of explicit uncertainty modeling and active evidence gathering when history alone is insufficient.
