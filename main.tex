\begin{abstract}
Embodied navigation systems increasingly use persistent spatial memories and
vision--language models for repeated tasks in familiar environments. These
memories preserve earlier observations for subsequent decisions, reducing the
need to reconstruct familiar scenes for each task. However, remembered states
can become outdated when objects move unobserved, including while an agent
travels toward a predicted destination. We study navigation under hidden world
evolution, in which an agent infers the latent current state from irregular
observation histories and revises its decisions as time elapses and new
evidence arrives.
We introduce \textbf{\evolvingworldnav{}}, an embodied agent that converts
timestamped 3D entity histories into a structured belief over
persistence at the last observed state and relocation to alternative states.
A frozen, zero-shot vision--language controller uses this belief to select
actions. An event-driven filter forecasts states at candidate arrival times,
incorporates newly informative RGB-D evidence through visibility-aware updates,
and replans as the world evolves. We also
introduce \textbf{\evolvingworldbench{}}, a human-trace-grounded benchmark for
evaluating state prediction and embodied decisions under controlled changes
before and during navigation. Across simulation benchmarks and physical robot
trials, \textbf{\evolvingworldnav{}} improves navigation success and search
efficiency relative to the evaluated baselines. Paired controls show that
temporal prediction is most useful when changes exhibit learnable regularity;
ablations demonstrate the benefits of preserving uncertainty and updating
beliefs from visual evidence.
\end{abstract}
