\begin{abstract}
Long-horizon embodied agents must remember a changing world, retrieve the right evidence for the current task, and prevent uncertain model outputs from silently becoming physical facts. We present \dragentos{}, a persistent embodied agent operating system that couples a typed agent controller with an evidence-grounded 4D World Memory. The memory lifts multimodal observations into a shared 3D frame, maintains stable entity identities with time-valid state versions, and links every assertion to its sensor provenance. A task-conditioned retrieval service combines descriptions, object crops, scene context, and explicit relations through rank fusion; a constrained vision-language model may select only a retrieved entity or abstain, while coordinates remain owned by mapping. Typed tools, closed-loop verification, conflict-aware reflection, and evidence-gated updates then connect memory to action without granting the language model authority over world state. We evaluate these memory-facing capabilities on LMEE-Bench and OpenEQA. The resulting design treats memory as an auditable system service rather than prompt context, enabling agents to query, act on, and responsibly revise experience over long horizons.
\end{abstract}

\subsubsection*{Ethics statement}
\dragentos{} is intended for research on embodied navigation, memory, and question answering. Persistent visual memory may capture people or private environments, and an erroneous retrieved state may cause unsafe physical behavior. Deployments should therefore obtain appropriate data consent, enforce retention and access controls, retain provenance for audit, and place platform-specific safety monitors outside the language-model controller. The benchmarks used here contain no new human-subject study by the authors.

\subsubsection*{Reproducibility statement}
